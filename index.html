SERVIDOR MINECRAFT RPG

MUNDO VIVO

Estamos construyendo un servidor RPG de Mundo Vivo sobre Minecraft. La V1.3 consolida el estado real del proyecto: Core, World, Kingdom, City y el sistema territorial ya cuentan con implementación validada. El siguiente gran paso es construir el sistema central de ubicación que conectará mundo, reino, ciudad y futuros establecimientos.

PLATAFORMA Paper 1.21.1
BASE TÉCNICA Java 21
ESTADO Pre-Alpha

¿En qué estamos trabajando?

La arquitectura completa está definida, pero los sistemas se implementan progresivamente. El primer objetivo es construir una base pequeña y funcional antes de escalar el mundo.

Actualizaciones

Registro público de checkpoints y cambios importantes del desarrollo.

06 OCT 2026

Arquitectura V1.3 — Territorio y siguiente checkpoint

La V1.3 consolida el estado real del proyecto. Core, World, Kingdom, City y Territory Selection ya están implementados. También están validados los territorios persistentes de reino y ciudad, la expansión territorial y el teletransporte con permisos.

06 OCT 2026

Nuevo objetivo: Location System

El próximo checkpoint será un sistema central de ubicación que determine el contexto del jugador mediante la jerarquía World → Kingdom → City → Establishment. Otros sistemas podrán reutilizarlo para leyes, guardias, comercio, misiones, impuestos, PvP y eventos.

06 OCT 2026

Establecimientos preparados para la siguiente etapa

La arquitectura incorpora un módulo genérico para herrerías, gremios de aventureros, tiendas, posadas, mercado, banco y otros establecimientos sin crear una clase independiente para cada negocio.

SEP 2026

Primer checkpoint técnico oficial

La base técnica fue validada: Java 21, Maven, Paper API, RPGPlugin y plugin.yml. El proyecto compila correctamente, genera ServidorRPG.jar y Paper carga el plugin en el servidor local.
